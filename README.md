## Titel

## Name der Studierenden

## Beschreibung der Funktionalität
Ein Bibliothekssytem, welches die verschiedenen Möglichkeiten einer Bücherei abbildet.
Digitalisierung der aufwändigen manuellen Verwaltung von Büchern, Benutzern und Mitarbeitern.
## Beschreibung des Kundennutzens
Der Kunde kann :
 - Benutzer verwalten
 - Bücher verwalten
 - Bücher ausleihen und zurückgeben
 - Informationen über Bücher abfragen
